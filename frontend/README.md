# MeChat frontend

The React and Vite client for MeChat, a safety-first AI mechanic assistant.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The development server runs on `http://localhost:5173` and proxies `/api` requests to the Express backend on port `5000`.

See the [main project README](../README.md) for setup, architecture, safety design, API documentation, and testing details.
